# KOMA Website

A responsive KOMA landing website.

## Files
- index.html — page structure and content
- styles.css — design and responsive styling
- script.js — mobile navigation
- assets/ — place KOMA logo, favicon, and real images here

## Customize
1. Replace `assets/favicon.ico` with your real favicon.
2. Replace the emoji-based phone illustration with screenshots of the actual KOMA app when available.
3. Change `hello@koma.kh` in `index.html` to the team's real contact email.
4. Update the feature text if KOMA's final feature set changes.

## Run
Open `index.html` directly in a browser, or deploy the folder to Vercel.
